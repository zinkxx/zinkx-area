# Security Policy

## Supported versions
Only the latest release receives fixes.

## Reporting a vulnerability
Please **do not** open a public issue for security problems. Use GitHub's
[private vulnerability reporting](https://github.com/zinkxx/zinkx-area/security/advisories/new) instead.
You can expect a first response within a few days.

Güvenlik açıklarını lütfen herkese açık issue yerine yukarıdaki gizli bildirim bağlantısıyla iletin.
